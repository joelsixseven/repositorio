Las páginas usan fotografías reales de Pexels mediante <img src="...">.
No se generaron fotografías ni se usa backend, Node, React o JavaScript.

Las imágenes son recursos externos de Pexels y requieren conexión a Internet
para mostrarse. Si quieres que el proyecto funcione completamente offline,
puedes descargar las fotografías desde sus páginas de Pexels y cambiar los
src por rutas locales.
