BLOOM - sitio educativo sobre el acné

Estructura:
- index.html -> portada y explicación general
- que-ocurre.html -> piel, capas y sebo
- curiosidades.html -> funciones de la piel
- factores.html -> factores y tipos de acné
- tratamiento.html -> opciones mencionadas en el material
- style.css -> estilos globales
- assets/ -> logo e imágenes proporcionadas por el usuario

IMÁGENES

Las fotografías proporcionadas por el usuario se mantienen dentro de assets/ para que sigan formando parte del diseño y se usen donde tienen más sentido: ejemplos visuales de acné, productos, lotus y cuidado facial.

Las fotografías adicionales se cargan desde enlaces directos de Pexels. Se eligieron imágenes distintas para evitar repetir la misma fotografía entre secciones y se adaptaron al contexto de cada página.

No se usan enlaces <a> sobre las fotografías. Las imágenes son elementos visuales y no funcionan como botones.

Nota: las imágenes remotas requieren conexión a Internet para mostrarse. El logo y las imágenes proporcionadas por el usuario permanecen locales.
